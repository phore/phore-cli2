# AI Usage Info

## Sinn der Library
`phore/cli2` ist eine kleine CLI-Dispatcher-Library für PHP.
Sie hilft dabei, öffentliche Methoden von Klassen als CLI-Commands („Actions“) bereitzustellen und Parameter automatisch aus `argv` zu mappen.

Praktisch ist sie vor allem für:
- kleine CLI-Tools ohne großes Framework
- Action-basierte Kommandozeilenprogramme
- einfache Parameterverarbeitung per `--name value`
- interaktive Eingaben
- formatierte Terminal-Ausgabe
- Presets über `cli_presets.ini`

## Beispiele
- `examples/creating-actions.php`
- `examples/helper-in.php`
- `examples/helper-out.php`
- `examples/helper-nc.php`
- `examples/helper-clipreset.php`

## Zentrale Klassen

### CliDispatcher
Haupteinstieg zum Registrieren und Starten von Command-Gruppen.
- `CliDispatcher::getCommandSet()` → kein eigenes Beispiel
- `CliDispatcher::autoload()` → kein eigenes Beispiel
- `CliDispatcher::addClass(string $className)` → `examples/creating-actions.php`
- `CliDispatcher::run(array $argv, ?int $argc = null)` → `examples/creating-actions.php`

### Attribute / Annotationen
Für die Beschreibung von Commands und Parametern.
- `Phore\Cli\Annotation\CliCommand::__construct(string|array $name, string $desc = "<no description>")` → aktuell kein eigenes Beispiel
- `Phore\Cli\Annotation\CliParameter::__construct(?string $name = null, string $desc = "<no description>")` → `examples/creating-actions.php`

### Input-Helper
Interaktive Eingaben auf der Konsole.
- `Phore\Cli\Input\In::AskLine()` → `examples/helper-in.php`
- `Phore\Cli\Input\In::AskBool()` → `examples/helper-in.php`
- `Phore\Cli\Input\In::AskMultiLine()` → `examples/helper-in.php`

### Output-Helper
Formatierte Text- und Tabellen-Ausgabe.
- `Phore\Cli\Output\Out::Table()` → `examples/creating-actions.php`, `examples/helper-out.php`
- `Phore\Cli\Output\Out::ParseMarkdown()` → kein eigenes Beispiel
- `Phore\Cli\Output\Out::TextDanger()` → `examples/helper-out.php`
- `Phore\Cli\Output\Out::TextWarning()` → `examples/helper-out.php`
- `Phore\Cli\Output\Out::TextSuccess()` → `examples/creating-actions.php`, `examples/helper-out.php`
- `Phore\Cli\Output\Out::TextInfo()` → `examples/creating-actions.php`, `examples/helper-out.php`

### Ncurses-Helper
Einfache terminalbasierte Tabellen- und Form-Darstellung.
- `Phore\Cli\Ncurses\Nc::Table()` → `examples/helper-nc.php`
- `Phore\Cli\Ncurses\Nc::Form()` → `examples/helper-nc.php`

### Presets
Lädt Kommando-Presets aus INI-Dateien.
- `Phore\Cli\CliPreset::__construct($iniFile = null)` → `examples/helper-clipreset.php`
- `Phore\Cli\CliPreset::loadPresets($iniFile)` → indirekt in `examples/helper-clipreset.php`
- `Phore\Cli\CliPreset::getPreset($presetName, &$arguments)` → `examples/helper-clipreset.php`
- `Phore\Cli\CliPreset::getHelp()` → kein eigenes Beispiel

## Niedrigere / interne Bausteine
Diese Klassen sind eher für die interne Verarbeitung relevant.

### Direkte Input-Verarbeitung
- `Phore\Cli\CLIntputHandler::askLine()` → indirekt über `examples/helper-in.php`
- `Phore\Cli\CLIntputHandler::askBool()` → indirekt über `examples/helper-in.php`
- `Phore\Cli\CLIntputHandler::askMultiLine()` → indirekt über `examples/helper-in.php`
- `Phore\Cli\CLIntputHandler::out()` → kein eigenes Beispiel

### Tabellenformatierung
- `Phore\Cli\Output\CliTableOutputFormat::__construct()` → indirekt über `Out::Table()` in `examples/creating-actions.php`, `examples/helper-out.php`
- `Phore\Cli\Output\CliTableOutputFormat::print_as_table()` → indirekt über `Out::Table()` in `examples/creating-actions.php`, `examples/helper-out.php`

### Fehlerausgabe
- `Phore\Cli\Exception\CliException::visualize()` → kein eigenes Beispiel
- `Phore\Cli\Format\ExceptionVisualizer::visualize()` → indirekt über `CliDispatcher::run()` in `examples/creating-actions.php`

### Command-Metadaten / Reflection
Interne Command-Strukturen für Dispatching und Parameter-Mapping.
- `Phore\Cli\Types\T_CommandGroup::CreateFromClassName()` → indirekt über `CliDispatcher::addClass()` in `examples/creating-actions.php`
- `Phore\Cli\Types\T_Command::CreateFromReflection()` → indirekt über `examples/creating-actions.php`
- `Phore\Cli\Types\T_Parameter::CreateFromReflection()` → indirekt über `examples/creating-actions.php`
- `Phore\Cli\Types\T_CommandSet`, `T_CommandGroup`, `T_Command`, `T_Parameter` → kein direktes Nutzungsbeispiel vorgesehen

## Empfehlung
Für neue CLI-Programme in diesem Paket normalerweise diese Bausteine verwenden:
- `CliDispatcher` für Actions
- `CliParameter` für Parameterbeschreibung
- `In` für Eingaben
- `Out` für Ausgabe
- `CliPreset` für wiederverwendbare Presets
- `Nc` für einfache interaktive Terminal-Oberflächen
